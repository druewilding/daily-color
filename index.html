Colors that go with it

    What is this?

    A color for every day

    Daily Color turns a date into a color. Every day has its own hex code, and because it's worked out from the date alone, everyone in the world gets the same color on the same day. There's no server, no database and no randomness, just a little bit of math.

    My website druewilding.com wears the day's color, so it looks different every day. You can see a whole year of colors on a calendar there.

      How it works

      The day, month and year are mixed together into one long string of digits. A small hash function turns that string into a number, and three bytes of the number become the red, green and blue of the color. A tiny change in the date gives a completely different color, so pale pinks, deep greens and bright yellows all turn up in no particular order.

      It uses the date where you are, so the color changes at your own midnight. Run it twice on the same day and you'll always get the same answer.

      The colors that go with it

      The other colors are the day's color turned round the color wheel: halfway round for its complement, a third of the way for a triad, and so on. The turning happens in OKLCH, a way of describing color that's closer to how we see it than RGB is, so every color keeps the same lightness and strength and they sit nicely together. A gray day has hardly any strength to keep, so its colors get a little extra, and there's always something colorful to go with it.

      The text on the color is black or white, whichever is easier to read. That's in the palette too, as contrast.

      Use it

      In a JavaScript or TypeScript project

      Install it from npm:

      npm install daily-color

      Then ask for today's color, or any other day's:

      import { getDailyColor } from "daily-color";

getDailyColor(); // today, e.g. "#000000"
getDailyColor(new Date(2027, 0, 1)); // New Year's Day 2027

      Or get the colors that go with it too:

      import { getDailyPalette, getPalette } from "daily-color";

const palette = getDailyPalette(); // or getDailyPalette(new Date(2027, 0, 1))
palette.color; // the day's color
palette.contrast; // "#000000" or "#ffffff", whichever reads better on it
palette.complementary; // one color
palette.splitComplementary; // two colors
palette.analogous; // two colors
palette.triadic; // two colors
palette.tetradic; // three colors

getPalette("#3fa2c1"); // the same, for any color

      And black or white text, whichever is easier to read on any color:

      import { contrastColor } from "daily-color";

contrastColor("#7ad2f9"); // "#000000"
contrastColor("#1935a4"); // "#ffffff"

      On a web page, without npm

      <script type="module">
  import { getDailyColor } from "https://www.druewilding.com/daily-color/dist/daily-color.js";

  document.body.style.background = getDailyColor();
</script>

      On the command line

      npx daily-color

      It prints today's color. Install it globally with npm install -g daily-color to get a dailycolor command. Name the colors you want to see the ones that go with it, and add a date to see another day: 

      dailycolor complementary
dailycolor triadic analogous
dailycolor all --date 2027-01-01
dailycolor --help

      On this page

      Add a date to the address to see that day, like ?date=2027-01-01. There's also a page of the next 36 days.
