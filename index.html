What is this?

A colour for every day

Daily Color turns a date into a colour. Every day has its own hex code, and because it's worked out from the date alone, everyone in the world gets the same colour on the same day. There's no server, no database and no randomness, just a little bit of maths.

My website druewilding.com wears the day's colour, so it looks different every day. You can see a whole year of colours on a calendar there.

    The next fortnight. Pick one to see it here.

    How it works

    The day, month and year are mixed together into one long string of digits. A small hash function turns that string into a number, and three bytes of the number become the red, green and blue of the colour. A tiny change in the date gives a completely different colour, so pale pinks, deep greens and bright yellows all turn up in no particular order.

    It uses the date where you are, so the colour changes at your own midnight. Run it twice on the same day and you'll always get the same answer.

    Use it

    In a JavaScript or TypeScript project

    Install it from npm:

    npm install daily-color

    Then ask for today's colour, or any other day's:

    import { getDailyColor } from "daily-color";

getDailyColor(); // today, e.g. "#000000"
getDailyColor(new Date(2027, 0, 1)); // New Year's Day 2027

    On a web page, without npm

    <script type="module">
  import { getDailyColor } from "https://www.druewilding.com/daily-color/dist/daily-color.js";

  document.body.style.background = getDailyColor();
</script>

    On the command line

    npx daily-color

    It prints today's colour. Install it globally with npm install -g daily-color to get a dailycolor command.

    Add a date to the address to see that day, like ?date=2027-01-01. There's also a page of the next 36 days.
